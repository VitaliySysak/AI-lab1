# AGENTS.md

Проєкт для вивчення AI агентів, написаний на Next.js з власними AI-циклами кодування.

## Стек

- TypeScript (`strict`), Next.js (App Router), Vitest.
- Node.js >=22.12.0, менеджер пакетів npm.

## Команди

- `npm run dev` — запуск сервера.
- `npm run build` — збирання додатку.
- `npm run lint` — лінтер.

- Заборонено змінювати будь-які файли тестів, контракти (схеми/типи) або конфігурації для вирішення помилки. Дозволено лише якщо людина про це чітко вказала.

## Межі

- `.env` і `.env.local` агент не читає і не редагує: секрети веде людина.

## Домовленості

- Модель обирається роллю з `src/models.ts` (`MODELS.cheap`), а не рядком-ідентифікатором.
- Ціни й дати зняття моделей звіряються зі сторінкою вендора, а не з пам'яті.
