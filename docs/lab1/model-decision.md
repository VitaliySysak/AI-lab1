## Ризики і відкат
- Що погіршилося:
  - вхідних токенів утричі більше (687 проти 188): у нової моделі довший системний шаблон і опис інструментів; для `:free` це не гроші, а для платного тарифу — так;
  - якість відповідей: впевнена помилка — «до півночі ~865 хв» порахувала за UTC, хоча сама назвала UTC+3 (траса 12:35:00); у привітанні зайво викликала `getTime` (траса 12:45:52);
  - облік токенів провайдера неточний: `textTokens: -33` при `reasoningTokens: 326` (cost.md);
  - дата зняття: для `:free`-моделей OpenRouter дати не оголошують — модель може зникнути зі списку будь-коли; тому id у змінній, а запасні перевірені (`google/gemma-4-26b-a4b-it:free`, `nvidia/nemotron-3.5-lightning:free`); 2026-09-28 частина з них теж давала 429 спільного пулу;
  - політика даних: безкоштовні моделі OpenRouter і Gemini free tier можуть використовувати запити для навчання — через деплой ідуть лише навчальні промпти без персональних даних;
  - відступ від AGENTS.md: модель обрано не роллю з `src/models.ts`, а рядком у змінній середовища — бо шлюзу немає в `CATALOG`, а список `:free` змінюється. Щоб повернутися до правила, треба додати в `CATALOG` запис шлюзу з ціною 0 і роль.
- За якої умови повернете попередню модель: коли Gemini free tier стабільно відповідає (без 503) і денного ліміту вистачає на навантаження деплою; або якщо всі перевірені `:free`-моделі OpenRouter недоступні довше доби. Відкат — `git revert 0da0288` і змінна `GOOGLE_GENERATIVE_AI_API_KEY` на Vercel (вона лишилась).
- Коміт зі зміною: [`0da0288`](https://github.com/VitaliySysak/AI-lab1/commit/0da0288ee0fe10220c71237461a83aae6c9a1337) — `app/api/agent/route.ts`; `src/models.ts` не змінювався (див. відступ від AGENTS.md вище).
