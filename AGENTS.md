# AGENTS.md

Проєкт для вивчення AI агентів, написаний на Next.js з власними AI-циклами кодування.

## Стек

- TypeScript (`strict`), Next.js (App Router), Vitest.
- Node.js >=22.12.0, менеджер пакетів npm.

## Команди

- `npm run dev` — запуск сервера.
- `npm run build` — збирання додатку.
- `npm run lint` — лінтер.

- Агент повинен виконати `npm run typecheck`, `npm run lint`, `npm test` та `npm run build` (і вони мають бути зеленими) ПЕРЕД тим, як звітувати «готово».
- Заборонено змінювати будь-які файли тестів, контракти (схеми/типи) або конфігурації для вирішення помилки. Дозволено лише якщо людина про це чітко вказала.

## Межі

- `.env` і `.env.local` агент не читає і не редагує: секрети веде людина.
- Тести не ходять у мережу і не викликають платні API.
- Агент не має права редагувати `package-lock.json`, папку `.next/` та конфіги інструментів (наприклад, `.claude/`) без прямого наказу.
- Агент повинен обов'язково зупинитися і запитати підтвердження людини перед: масштабним видаленням чи переписуванням існуючого коду або файлів, деструктивними операціями в терміналі, `git push` або зміною залежностей у `package.json`.

## Домовленості

- Модель обирається роллю з `src/models.ts` (`MODELS.cheap`), а не рядком-ідентифікатором.
- Ціни й дати зняття моделей звіряються зі сторінкою вендора, а не з пам'яті.
- Повідомлення комітів пишуться за форматом Conventional Commits (`feat:`, `fix:`, `chore:`).
